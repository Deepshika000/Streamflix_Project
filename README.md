## 🎯 Project Overview

StreamFlix needed a single view of how its audience engages with content. This dashboard brings together viewing behavior, audience demographics, and content licensing data so teams can see what people watch, on which devices, and which titles perform best.

## 📊 What the Dashboard Covers

- Streaming engagement:watch duration across devices
- Viewer demographics:who the 15K active users are
- Content performance:top movies and review trends
- Licensing timelines:tracking content availability windows
- Interactivity:KPI cards and slicers for quick filtering

## 🧩 Challenges & Solutions

| Challenge | Solution |
|-----------|----------|
| Accurate watch duration across devices and top movies: time formats were inconsistent | Cleaned and standardized time formats, then wrote custom DAX measures |
| Designing a cohesive dark-themed layout: balancing many visuals on one canvas | Iterated on custom borders, KPI cards, and interactive slicers to keep the page clean and readable |

The result is a dashboard that is both insightful and visually engaging.

## 🛠️ Tools & Skills Used

- Power BI (dashboard design, interactive slicers, KPI cards)
- DAX (custom measures)
- Power Query (data cleaning, time-format standardization)
- Data visualization & UI/UX layout design
